Projeto de Extração de Tarifas - Cemig
Este projeto tinha como objetivo extrair as tarifas de energia elétrica das bandeiras tarifárias (vermelha, verde, amarela) do site da Cemig, utilizando a biblioteca Selenium para automação do navegador.

🚨 Problema Encontrado
Apesar de todas as tentativas, o código não conseguiu finalizar corretamente o processo do Selenium, resultando em um erro de "Permission Denied" ao tentar fechar o navegador.

🔧 Tecnologias Utilizadas
Python 3.x
Selenium
ChromeDriver
